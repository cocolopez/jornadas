# Jornadas (Android nativo)

1. Instalá Android Studio (Koala o más nuevo) y abrí esta carpeta (File > Open).
2. Esperá el "Gradle Sync". Si se queja de que falta el wrapper, aceptá lo que te proponga
   o usá la versión de Gradle 8.7.
3. Conectá el celu (depuración USB) o creá un emulador y tocá Run.
4. Para un APK: Build > Build Bundle(s) / APK(s) > Build APK(s).

La primera vez que abre, carga los días de Perez2023.xlsx (Andres y Eloisa, dic 2022 - feb 2023)
con pago y viáticos en $0: andá a Personas > Editar, poné las tarifas y tildá
"Aplicar a los días ya cargados".
